最終更新: 2026-09-28 / 作業ブランチ: `claude/loving-wright-wu1w7r`（`main` には未反映）

## このプロジェクト

- 「ダルライザー THE GAME」: ブラウザで動くベルトスクロールアクション。アーケード版ダブルドラゴンがモチーフ。
- **`index.html` 1ファイルだけ**でできている（約74MB）。画像・音声は全部 base64 で埋め込み。
  - コード部分は約50KB。巨大な行（base64）があるので、エディタやツールで開くときは注意。
  - 画像: `const SPR_ACT={...}`（キャラ）、`BG_IMAGES`、`FRONT_IMAGES`
  - 音: `const AUDIO_xxx = 'data:...'`
- 公開: GitHub Pages（https://dharuriser.github.io/DharuriserTHEGAME/ 、おそらく `main` から配信）
- オーナーはプログラミング初心者。説明は日本語で、専門用語は噛み砕く。

## コードの地図（index.html 内）

| 探す文字列 | 内容 |
|---|---|
| `const ANIM={` | キャラごと・状態ごとの [画像名, コマ番号の並び, 1コマのフレーム数] |
| `WALK_STRIDE` / `FOFS` / `FLOOR_F` | 歩行コマを進める距離 / 歩行コマの位置ズレ補正 / 床に倒れるコマ |
| `function ds(` | スプライト描画（白フラッシュ `dsWhite`、傾き `dsRot` 対応） |
| `function playSFX(` / `const SYNTH=` | 効果音（初回デコードしてキャッシュ）/ プログラムで合成する効果音 |
| `function update(` | ゲームの1フレーム分の処理（入力・攻撃判定・敵） |
| `function updateEnemyAI(` | 敵AI（性格ごとの状態遷移） |
| `function draw(` | 描画 |
| `function loop(` | 固定60回/秒のゲームループ |

## このブランチでやったこと

1. **歩行**: 往復再生(1234321)で同じ足が2回続いていた → 一方向ループ(2→3→4→1)。移動距離でコマを進める（足滑り防止）。コマごとの腰のズレを補正。敵も同様。
2. **効果音**: 打撃音がボタンを押した瞬間に鳴っていた → 命中の瞬間に。振りに風切り音。ガードの8bit「失敗」ジングルを金属音に。被弾音・着地音・倒れる音を追加。毎回デコードしていたのをキャッシュ化。
3. **速度**: 画面のリフレッシュレート依存（120Hzで2倍速）→ 固定60回/秒。
4. **キャラが消える**: 被弾時・無敵時に描画を省いていた → 白フラッシュ／半透明点滅。
5. **必殺技**: 至近距離で空振り → 溜めてから突進＋体全体の当たり判定。
6. **ダブルドラゴン実測値に寄せた**（プレイ映像13秒を1コマずつ解析、キャラの身長比で換算）:
   - 横移動 3.0px/フレーム（DD: 1秒に身長の1.74倍）、縦は横の0.8倍
   - パンチ: 振りかぶり6/伸ばし6/戻し6フレーム
   - ジャンプキック: （その後、オーナーの希望で下記9のライダーキック風に置き換え）
   - 敵ののけぞり12フレーム、パンチの押し出しは小さく
   - DDの歩きは足が滑っている（ポーズ切替0.17秒ごと・1歩0.68秒）が、本作は足を滑らせない方針
7. **ダウン〜起き上がり**: コマ順が逆だった（ひざ立ち→仰向け→直立）→ 仰向け→ひざ立ち→直立。敵の被弾も「直立→のけぞり」の逆順だったのを修正。主人公の被弾は吹き飛びコマをやめ、描画時に体を後ろへ傾ける。
9. **飛び蹴り（←→+X）をライダーキック風に**: しゃがむ→高く跳ぶ→前方宙返り→斜め下へ急降下（残像・つま先が光る）→着地。
   新しい絵は描かず、今のキック画像のコマに高さ・回転・移動をプログラムで付けている（`riderKick()`、`RK`、`drawRiderKick()`）。
   空中にいる間（`pAir()`）は敵の攻撃が当たらない。急降下の後半だけ命中する。全体51フレーム。
10. **開発用**: `[` `]` キーで移動速度を調整（画面に表示）。速度が決まったら削除する。
